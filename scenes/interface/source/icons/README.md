# Hugeicons source snapshot

The sample interface uses Hugeicons Free Stroke Rounded. Its font was downloaded from the official CDN on 16 September 2026:

- CSS: https://use.hugeicons.com/font/icons.css
- WOFF2: https://use.hugeicons.com/font/hgi-stroke-rounded.woff2?t=1788885671703
- License: https://github.com/hugeicons/hugeicons/blob/main/LICENSE.md (retained in LICENSE)

`icons.css` contains the original base class and the four glyph mappings used by this fixture. The font is local so a frozen scene snapshot includes its icons and exports work without the CDN. The editor itself uses the official CDN directly.
