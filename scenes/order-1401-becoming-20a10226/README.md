# Order 1401 — Becoming

A fifteen-second, continuous macro-to-wide construction of the existing Admin Next Order #1401 interface. The first four seconds travel across the payment hairline and arriving rows. The lens rises into the fulfillment card as its real product images and status badge appear, continues past the customer note and title, then pulls back during seconds 10–15 to reveal the complete interface.

Every visible UI pixel comes from the existing packaged browser source. Payment and fulfillment dividers draw from left to right; rows translate into place; product images and payment marks have a small overshoot. Panels descend in depth independently. The final camera slows to rest with the complete screen inside the frame.

## Editing

- **Continuous camera:** expandable travel intervals. Detail distance changes macro framing; Final framing changes the ending's margin.
- **Layers settle:** expandable section timings and Layer separation.
- **Interface builds:** individual element timings and Small overshoot.
- **Screen resolves:** the original surrounding interface arrives during the pullback. The composer remains in its original browser backdrop to preserve its blend dependency.
- Shared Camera settings own depth of field. The scene registers the moving subject as its focus reference; the nearly frontal ending returns the full screen to focus.

Scene sampling uses absolute time, including backward seeks. Current track intervals drive all motion. Output is 1920×1080, 60 fps; UI capture is 4× (5760×4000), with the original 1440×1000 CSS layout.
