The browser layout was checked at the narrow Codex panel width. A source subject was selected and its ID, source ID, mode and sampled route appeared in fresh context.

A slider drag created exactly one history entry; the visible Undo button restored the original value. The original scene settings remain unchanged.

Closing the desktop window left both browser contexts connected; browser playback reached the end normally. A browser-targeted capture produced PNG plus JSON with matching presented time/revision. The final renderer/source-route contract produced `exports/interface-19f741bf.mp4`: **240 frames, 1440 × 900, 30 fps, 8 seconds**, completing capture/encode/verification in **14.1 seconds**. The earlier interruption/cancellation/MCP results above describe the initial runtime tests. This revision reran full export and viewer/file/history behavior; it did not repeat every forced-worker-crash scenario. Tests use temporary projects for history and security checks. History has no automatic pruning, raw file writers cannot supply intent/ownership metadata, and browser tabs subject to aggressive background throttling can become stale until they resume. Native UI source adapters remain out of scope.

## Declared UI layers

Typecheck, production build and all **18 behavioral tests** pass. The new tests cover layer ID validation and hierarchy/layout alignment while retaining authored transforms. The Electron integration check (`npm run test:layers`) exercises real browser paint, with rounded corners, shadow padding, nested extraction, ancestor clipping, hidden elements and an optional element mounting/unmounting. It verifies that the base removes extracted paint, padding is transparent, unchanged revisions skip captures while refreshing routes, backward sampling reproduces pixels, and an injected mid-pass failure restores source styles and private attributes. Invalid/ambiguous selectors and parent ordering return specific errors across the browser boundary.

Recompositing the synthetic fixture's base and three visible layers gave a mean RGB channel error of **0.183 on a 0–255 scale**; **0.18%** of pixels differed by more than 8 in any channel. Small crop/raster antialiasing differences remain, so universal pixel-perfect reconstruction is not claimed. A separately bundled React/TSX fixture mounts real nested components, updates its button through the source adapter, and reproduces the earlier layer pixels when seeking backward. No React-specific capture code is used.

The included scene now lifts navigation, its nested active item, summary and task regions. At 4s their local Z values are 1.15, 0.207, 0.713 and 0.322; at 7.8s all return to zero. The final 4s → 7.8s → 4s captures reproduced a byte-identical 4s PNG in this run. The camera framing keeps the separated composition inside the output. Browser inspection confirmed the layer list/selection and all four cue tracks at the narrow Codex panel width. Camera drag changed orbit; 2D drag changed pan; scrolling changed zoom; Fit reset inspection. Fresh context reported the presented layer hierarchy and transforms, selected `ui:navigation`, and no paint warnings for the demo.

The final layered video is `exports/interface-5734e1aa.mp4`: **1440 × 900, 30 fps, 240 frames, 8 seconds**, completing capture, encoding and verification in **34.4 seconds** on this machine. The worker checked FFprobe metadata and fully decoded the MP4 before publication. This is slower than the earlier whole-page example: each changed source frame now captures the full page, base and four visible regions. Unchanged source revisions still reuse every pass. No shared GPU texture transfer is implemented.

Layers require deliberate selectors and grouping. The remaining page is one base behind the declared regions; overlapping foreground content must also be declared where paint order matters. Backdrop filters, blend modes and ancestor opacity/filter can depend on shared paint and produce warnings. Clipping remains baked; open Shadow DOM is rejected, and closed shadow internals/cross-document selection require adapters. Large production apps, Svelte, canvas/iframe internals, multiple layered sources and heavy compositing dependencies have not been acceptance-tested. See `docs/layers.md` for the contract and `.agents/skills/ui-layers/SKILL.md` for the reusable agent workflow.

## Hugeicons migration (16 September 2026)

Render is text-only. Toolbar, transport, settings, dropdown chevron and timeline zoom glyphs use the shared Hugeicons component with the official `use.hugeicons.com` stylesheet/font CDN. The available public style is Stroke Rounded; Solid Rounded requires a Pro icon-set URL. Old custom SVG paths and Dial Kit's unused icon map were removed. Browser inspection confirmed the expected glyphs, Hugeicons font family and no console warnings/errors.

The sample interface's navigation, add action and completion marks use the same family. Its font and four CSS glyph mappings are a local CDN snapshot, with source/hash/license recorded alongside them, so export snapshots include the actual font. Its edits were applied as one scene history group. A separate viewer verified the sample without changing the main viewer's time or inspection.

Typecheck, build and all 21 existing tests passed. A full export (`d6a57f4d-cf71-440c-85d4-5cdd81d65a7b`) completed in 34.992 seconds. FFprobe confirmed 1440×900, 30fps, 240 frames and 8.000 seconds.
