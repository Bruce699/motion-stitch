# Editor design system

Tilt uses a selective source fork of [Dial Kit](https://github.com/joshpuckett/dialkit). Its controls and layout use the Codex reference's resolved light/dark colors. The source version, license and local adaptations are recorded in [UPSTREAM.md](../src/renderer/vendor/dialkit/UPSTREAM.md).

`vendor/dialkit/theme.css` supplies the selected control rules. `theme.css` maps their semantic tokens to a small exact subset of the supplied Codex archive's `codex.css` (build 26.908.70816; source hash is recorded in the file). `style.css` supplies Tilt's shell layout and compatibility overrides. Use the `--dial-*` tokens, 36px filled controls, compact 28px toolbar actions, restrained system type, Geist Mono values, and subtle tonal separation. Keep the canvas, timeline and parameter panel as the primary structure. Scene content has its own styling.

## Shared controls

The editor reuses Dial Kit's filled slider, segmented control, toggle, dropdown, XY pad, color picker and autosizing text field. XYZ vectors and number-only fields use Tilt's validated draft input within the same visual treatment. Add scene controls through `scene.json.parameters`; see [parameters.md](parameters.md). Do not create a private widget for every shader.

Keep keyboard navigation, visible focus, accessible names, Escape dismissal and popup collision handling. Use `src/renderer/icons.tsx` for every editor icon. It uses Hugeicons from the official CDN; do not add hand-drawn glyphs or mix icon libraries. Render is text-only. Do not invent brand marks. Retain the MIT notice when adapting upstream code. Motion's springs are an implementation dependency; Dial Kit itself is not installed.

All creative values flow through Tilt's file journal. Control gestures share an ordered save queue and finish one edit group. No independent preset store, browser-only values, or hidden animation loop. Reduced motion disables decorative spring settling/transitions; it does not alter authored animation or direct inspection.

## Timeline and layout

The controlled timeline uses Dial Kit's overview, adaptive ticks, playhead, lanes and anchored zoom patterns. Drag to seek, Option/Alt-drag to zoom, Shift-drag to reset and seek, and Option/Alt-wheel to zoom under the pointer. The overview navigates the full scene; a horizontal scroll track appears when zoomed. Arrow keys step one frame, Shift-arrows ten frames, Home/End go to the bounds. Click or double-click a bar to select its contextual inspector above the global controls. Drag its body to move, or either handle to trim, with frame snapping and a one-frame minimum. Arrow keys on a focused bar or handle edit one frame (Shift: ten). Escape cancels a drag or clears selection. Each completed drag is one file-backed undo step; cue markers preserve their relative timing. Tracks declare `parameterKeys` to associate existing scene parameters with their contextual inspector. Scene code explicitly samples track timing; the editor does not infer an animation from a cue. Groups start collapsed, expand into child rows, and move or retime their descendants together. The inspector shows Start and Duration (or the authored duration label); these are the actual interval. See [animation groups](animation-groups.md).

The theme follows the device through CSS `prefers-color-scheme`, from the first styled paint and live when the device preference changes. There is no toggle, saved preference, or URL override. Light uses Codex's white surface, #f6f6f6 workspace and #1a1c1f text; dark uses #181818 surface, #141414 workspace and #dfdfdf text. Controls, popovers, borders, focus rings, errors and primary buttons use the reference's semantic colors and alpha values. The Electron window's initial background follows the same device preference. Colors, shaders and exports do not inherit the editor theme. The full-height sidebar and bottom timeline use react-resizable-panels (the same primitive as shadcn/ui), starting at 304px and 250px. Drag or use the keyboard on their separators to resize; panel sizes persist locally as inspection layout. The main header belongs to the left workspace, including view controls and render actions. Active render jobs show a spinner next to Render; the timeline omits the FPS readout. Canvas fitting measures the actual available space. Do not reset a user's pan, zoom, orbit or time while restyling.

Geist Mono is bundled locally with its SIL license. Hugeicons icon fonts load from `https://use.hugeicons.com/font/icons.css`, permitted only for styles/fonts by the editor CSP. The public CDN provides Stroke Rounded; Solid Rounded requires a licensed Pro set URL. Do not simulate solid icons by thickening strokes. The sample source UI uses a local snapshot of the same CDN font so icon pixels are part of its frozen export. Only the selected Codex theme tokens are carried in the product; the full archive stylesheet, component recipes and icons are not imported. Dial Kit geometry, typography and interaction patterns remain intact. The timeline retains its existing authored cue colors and adaptive light-mode tint because Codex has no corresponding timeline palette.
