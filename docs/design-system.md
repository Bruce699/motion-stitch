# Editor design system

Tilt uses a selective source fork of [Dial Kit](https://github.com/joshpuckett/dialkit). Its controls and layout use the Codex reference's resolved light/dark colors. The source version, license and local adaptations are recorded in [UPSTREAM.md](../src/renderer/vendor/dialkit/UPSTREAM.md).

`vendor/dialkit/theme.css` supplies the selected control rules. `theme.css` maps their semantic tokens to a small exact subset of the supplied Codex archive's `codex.css` (build 26.908.70816; source hash is recorded in the file). `style.css` supplies Tilt's shell layout and compatibility overrides. Use the `--dial-*` tokens, 36px filled controls, compact 28px toolbar actions, restrained system type, Geist Mono values, and subtle tonal separation. Keep the canvas, timeline and parameter panel as the primary structure. Scene content has its own styling.

## Shared controls

The editor reuses Dial Kit's filled slider, segmented control, toggle, dropdown, XY pad, color picker and autosizing text field. XYZ vectors and number-only fields use Tilt's validated draft input within the same visual treatment. Add scene controls through `scene.json.parameters`; see [parameters.md](parameters.md). Do not create a private widget for every shader.

Clickable editor controls and links use the default arrow cursor, including the local Dial Kit controls. Text entry, resizing and direct manipulation retain their contextual cursors. Keep keyboard navigation, visible focus, accessible names, Escape dismissal and popup collision handling. Use `src/renderer/icons.tsx` for every editor icon. It uses Hugeicons from the official CDN and the local transport-path adaptation; do not add hand-drawn glyphs or mix icon libraries. Render uses the shared upward share icon and a 28px filled button with 10px corners. Do not invent brand marks. Retain the MIT notice when adapting upstream code. Motion's springs are an implementation dependency; Dial Kit itself is not installed.

All creative values flow through Tilt's file journal. Control gestures share an ordered save queue and finish one edit group. No independent preset store, browser-only values, or hidden animation loop. Reduced motion disables decorative spring settling/transitions; it does not alter authored animation or direct inspection.

## Timeline and layout

Native window resizing preserves sidebar widths and timeline height in pixels, subject to minimum/maximum constraints; the canvas absorbs the remaining space. Preview fitting coalesces into one animation-frame callback, reads layout before writes, and redraws only when its backing buffer changes. Panel persistence waits for resizing to settle and flushes on page exit; collapse preserves the last expanded size. These changes never alter authored output resolution or scene time.

The 2D / Camera selector floats at the bottom center of the viewer, 16px above its lower edge and the timeline. It follows the viewer as sidebars resize or collapse, without changing canvas fitting. It uses the shared segmented control, surface and shadow tokens; the 1 / 2 keyboard shortcuts remain available.

For native compositions without browser sources, multiple authored cameras appear in this same selector by their saved names. The 1 / 2 shortcuts select the first two cameras. These choices preserve the playhead and change only the preview camera; the output camera remains explicitly controlled by Use for output. Browser compositions retain the direct 2D source / Camera selector.

The controlled timeline adapts Dial Kit's adaptive ticks, playhead, lanes and anchored zoom patterns. Playback and one frame timecode occupy the label column of the ruler row. There is one scrubber and one compact playhead handle; no overview, duplicate time badge or zoom buttons. Drag to seek, pinch or Option/Alt-wheel to zoom under the pointer, and scroll horizontally (or Shift-wheel) to pan. Option/Alt-drag also zooms; double-click or press 0 on the ruler to fit. Focused +/− keys zoom around the center. Shift-drag resets and seeks. Arrow keys step one frame, Shift-arrows ten frames, Home/End go to the bounds. Click or double-click a bar to select its contextual inspector above the global controls. Drag its body to move, or either handle to trim, with frame snapping and a one-frame minimum. Arrow keys on a focused bar or handle edit one frame (Shift: ten). Escape cancels a drag or clears selection. Each completed drag is one file-backed undo step; cue markers preserve their relative timing. Tracks declare `parameterKeys` to associate existing scene parameters with their contextual inspector. Scene code explicitly samples track timing; the editor does not infer an animation from a cue. Groups start collapsed, expand into child rows, and move or retime their descendants together. The inspector shows Start and Duration (or the authored duration label); these are the actual interval. See [animation groups](animation-groups.md).

The theme follows the device through `prefers-color-scheme` until the person chooses an appearance. Playground and Library share a sun/moon icon button at the top right of the header, aligned with Home and the project name using the toolbar's existing edge padding. The button switches light/dark appearance and remembers the choice locally across reloads; its accessible name describes the next mode. Light uses Codex's white surface, #f6f6f6 workspace and #1a1c1f text; dark uses the supplied #141414 swatch for both the editor surface and workspace, with #dfdfdf text. Controls, popovers, borders, focus rings, errors and primary buttons follow the same selected palette. The Electron window's initial background follows the device preference. Source scenes, colors, shaders and exports do not inherit the editor theme. The inspector below the toolbar and bottom timeline use react-resizable-panels (the same primitive as shadcn/ui), starting at 304px and 180px. Drag or use the keyboard on their separators to resize; panel sizes persist locally as inspection layout. The 52px main header spans the full editor, including view controls and render actions. Active render jobs show a spinner next to Render; the timeline omits the FPS readout. Canvas fitting measures the actual available space. Do not reset a user's pan, zoom, orbit or time while restyling.

Geist Mono is bundled locally with its SIL license. Hugeicons icon fonts load from `https://use.hugeicons.com/font/icons.css`, permitted only for styles/fonts by the editor CSP. The public CDN provides Stroke Rounded; Solid Rounded requires a licensed Pro set URL. The workspace Play/Pause control fills the unchanged closed paths from the MIT-licensed free package, with no stroke; this narrow adaptation is documented in [Hugeicons UPSTREAM.md](../src/renderer/vendor/hugeicons/UPSTREAM.md). Do not simulate solid icons by thickening strokes. The sample source UI uses a local snapshot of the same CDN font so icon pixels are part of its frozen export. Only the selected Codex theme tokens are carried in the product; the full archive stylesheet, component recipes and icons are not imported. Dial Kit geometry, typography and interaction patterns remain intact. Timeline labels use the eight reference colors in `src/core/track-colors.ts`, with saved per-track hex values and an adaptive light-mode tint. See [track colors](animation-groups.md#track-colors) for assignment guidance.

The composition browser lives beside the viewer, above the timeline. Both side panels, the camera picker and settings popup use `--dial-glass-bg` for the same opaque editor surface; `--dial-surface` is reserved for filled controls. The 52px toolbar spans the full editor above both sidebars, keeping the collapse buttons at fixed coordinates as panels open and close. In Electron, empty space in the editor and Home toolbars uses native window dragging and title-bar double-click behavior. Only controls and popovers opt out; the composition title still supports double-click to rename. A collapsed timeline keeps playback, the playhead ruler, time and duration in a 48px strip. Collapse and resize preserve the mounted viewer and authored state.

Errors use a persistent amber warning button beside Render. Its Radix Popover uses the shared surface, focus handling, Escape/outside dismissal and viewport collision handling. A short summary leads; Technical details expands the complete diagnostic text. Closing the popover leaves the warning available; Dismiss acknowledges it, and Retry uses the editor's rebuild action. A screen-reader status announces new errors without stealing focus. `data-transport-keys="ignore"` preserves native Space interaction inside the popover and on its trigger.

Home lists project folders opened by Tilt. Its local library is stored under the system application-data directory in `Tilt/projects`, with one record per canonical folder path. Source files and history remain inside each project. Open folder accepts an existing Tilt project; New project creates a new folder with one blank composition. Each project retains its own runtime and render queue. Opening another project navigates to its local runtime; the original runtime and any exports continue. Verification can isolate the library with `TILT_PROJECTS_DIRECTORY`.

## Project workspace

Opening a project from Home lands in Playground. The centered Playground / Library pill switches the project workspace; opening a composition enters the detailed editor, whose back button returns to the previous workspace tab.

Playground uses a shared, absolute preview clock above a resizable clip canvas. Each selected sequence retains at most three prepared composition renderers. After the first visible frame, it warms the next clip and then the previous clip in the background, including source capture and a rendered frame, so cuts and backward scrubbing reuse ready resources. Background warming is serialized across comparison previews. Engines are released on eviction, revision changes and unmount; this cache does not change scene files or export quality. Workspace playback uses isolated density-1 source capture and textures capped at 1024px, so preloading transfers fewer pixels; the detailed editor retains full capture quality. Seek requests invalidate older pending presentations, and the transport only acknowledges the latest completed preview batch. Click a tile to play its composition; Shift-click toggles comparison previews, capped at four. Three previews use two centered rows with one centered item below the first pair. Drag a tile's head or tail near an exposed endpoint to snap the compositions into a sequence. Dragging a sequence head moves the chain; dragging a later tile separates that tile and its following clips. The square broken-chain button disconnects selected chains immediately, including while an earlier save is queued. Routine saves do not insert a transient label or dim this action; save failures remain visible. Position edits can queue while an earlier canvas save is pending; completed saves preserve any active drag draft. Moving or joining unrelated clips leaves the selected preview and its clock running, because playback identity follows only the selected chains. Arrow keys move focused tiles; Shift increases the step. Enter or Space previews a focused tile, and double-click opens it in the editor.

Selected clips have no outline or shadow; keyboard focus underlines the title. Within snap range, a rounded line fades in and grows at the midpoint of the current gap, blending the two endpoint colors. The facing corners progressively flatten as the endpoints align, remain square when joined, and recover their configured radius on separation. Released clips settle into the join without delaying file persistence. Reduced motion removes the decorative settling and cue growth.

Adding a Playground comparison fades the new preview from zero opacity and scales it from 60% to 100%, while the existing frames move and resize into their new slots. All motions run together for 300ms; opacity fades linearly while scale and layout use `cubic-bezier(0.5, 0, 0, 1)`. Each video has 2px corners. In light mode, a 1px light gray (#e8e8e8) stroke overlays its bounds to preserve the canvas aspect ratio; dark mode has no stroke. Frame fitting resolves in CSS before layout measurement; stable keyed preview renderers stay mounted, and compositor transforms animate the layout without resizing their backing canvases on every frame. Rapid selection changes retarget the current motion. Reduced motion presents the final layout immediately.

File-backed snapping values include joined box gap, snap reach, settle/corner durations, easing and corner anticipation. Snap line values include visibility, width, starting and ending lengths in canvas pixels, rounding, opacity, fade in/out, response duration, proximity response curve, gradient direction in degrees and automatic or custom gradient colors. Length interpolates from the starting value at the edge of snap reach to the ending value at alignment, and shortens as the endpoints move apart. The response duration smooths these distance-driven changes; entering range alone does not animate to full length. Ending length cannot be smaller than starting length. Reduced motion keeps proximity feedback immediate. These values persist in `playground.json.ui`; the same gap and reach drive drawing, reconciliation and snapping. The play pin uses the preview's successfully presented frame time, moving through the active clip and onto the next at a sequence cut without another clock. It follows pause, seek, looping and comparison playback. Its visibility, width, head size and color remain file-backed.

The project-root `playground.json` stores positions, sequence connections, canvas height, source-time feedback marks, composition labels/versions, UI settings, and optional tags by composition ID. Saves validate the graph, use an atomic write, and reject stale revisions. Conflicts retain the unsaved arrangement and expose Reload saved canvas. Clip content remains in its original scene files. Connected sequences share preview playback; they do not rewrite their source compositions.

Library uses real rendered thumbnails, starts preview playback on hover or keyboard focus, and opens the editor on double-click or Enter. Scene and Version dropdowns derive their choices from composition names: `Order 1401 — Becoming` means scene `Order 1401`, version `Becoming`. A spaced hyphen or slash, en dash, or em dash separates the first scene prefix from the complete version suffix. For example, `question / two` shares the `question` scene filter and canvas pile with `question - typing`; slashes without surrounding spaces remain part of the scene name. Names without a suffix remain standalone scenes. Version choices follow the selected scene, and switching scenes clears the version filter. Search matches the full name, scene, named version and existing tags. Saved title overrides in `playground.json.compositions` take precedence over the source name. Cards and canvas clips show the full name and seconds, without separate version-number badges; legacy numeric metadata remains file-compatible but does not drive naming, filters or layout. Static thumbnail generation stays serialized and begins near the Library viewport. Revision keys include each composition and its reachable children, so unrelated edits preserve cached posters. A bounded IndexedDB cache retains up to 64 derived JPEGs across page reloads, with in-memory rendering as the fallback when storage is unavailable. Thumbnail capture uses separate density-1 browser source sessions through the shared capture pipeline; source CSS bounds, authored scene dimensions and capture settings remain unchanged. Library hover playback uses the compact hover quality and isolated thumbnail source sessions, keeping main Playground playback independent. Unused queued thumbnail work is canceled. Live workspace previews have bounded output and texture resolutions, while the editor and exports retain their authored quality. The hidden editor compositor is released while the project workspace is open.

The workspace pill has equal compact segments, with black and white for the active selection. Playground fits previews into the available area with adjustable insets, initially 12px, and a separate transport strip. The stage and strip use the same opaque surface as the navigation bar (white in light mode). The strip contains a 32px square black Play/Pause button with solid white icons and 8px corners, playback speed and a simple seek handle. The round seek thumb is black in light mode; dark mode uses a muted-gray thumb over a medium-gray track that stays visible against the stage. Existing saved marks remain as downward-pointing triangle markers on the seek line and return to their saved source timestamps. Playback speed is inspection state and does not retime authored content. The canvas retains one resize line with a center handle, matching 28px opaque gray reset, zoom and disconnect controls at bottom left, with a consistent 8px gap between every action, no enclosing zoom backdrop and no permanent instruction/status bars. Library uses a plain category dropdown, an icon-only search field, and a compact density slider for 1–8 columns (default 4). Column count is a saved inspection preference, not authored composition state. Cover-fitted thumbnails use white title and duration text with difference blending, without a gradient or text shadow; durations use seconds (8s). Library text uses the system sans throughout. Workspace text uses the system sans. Clips are solid color boxes with a left-aligned title and right-aligned seconds; separate version chips are omitted. They have no painted end handles or ticks. Hover previews show no pause icon or progress indicator. The single-pixel resize line connects directly through its center handle using one opaque neutral color, has no surrounding white strip or handle halo, and retains keyboard focus and the row-resize cursor. Empty preview guidance is centered in the available preview area. Preview frames have 2px corners, with an inset 1px light gray stroke in light mode and no stroke in dark mode; their fitting area excludes transport. Content inside compositions retains its own fonts.

Canvas pinch zoom and the compact − / + controls change inspection scale from 25% to 200%; Reset can extend the lower limit to fit a long lineup on a narrow screen. There is no zoom percentage readout. Zoom preserves the content point beneath the gesture or viewport center; ordinary two-finger scrolling pans the canvas with both scrollbars hidden. Clip dragging converts screen and scroll deltas back to canvas coordinates, preserving authored positions and snap behavior at every scale. Reset first disconnects every clip, then arranges distinct scene names horizontally and stacks their named versions vertically in the saved canvas order. Reset preserves that family order even when the composition catalog refreshes. Each column reserves the width of its widest version, with 64 canvas pixels between scene piles and 16 pixels between their versions, and the viewport fits all clips above the canvas controls. Arrangement saves through the workspace revision queue, while zoom remains inspection state. Zoom never changes scene transforms or playback.

The workspace Dial Kit launcher and panel are removed from Playground and Library. Saved UI settings still apply from `playground.json`; the retained control definitions below describe their values and ranges. The View pill section exposes font size (10–24px), horizontal padding (6–40px) and vertical padding (4–20px), with live preview and exact numeric entry. Defaults are 13px type, 24px horizontal padding and 10px vertical padding. These save to the existing `playground.json.ui.switchFontSize`, `switchPaddingX` and `switchPaddingY` fields; each segment retains equal width. Playground adds Play stage controls for Above frame, Below frame and Side padding (0–120px, each initially 12px). Playback controls expose Row height (32–120px, initially 56px), Control spacing (0–32px, initially 12px), Side inset (0–120px, initially 20px), and Maximum width (320–1600px, initially 880px). Preview fitting uses the actual insets; vertical insets are limited by the available stage height. These seven values save in `playground.json.ui`; Reset stage spacing restores only these seven defaults. Playground also includes a Preview spacing section. Its Horizontal gap and Vertical gap sliders independently control the space between preview windows from 0 to 120px, starting at 20px and 16px. Preview fitting includes these gaps, so three previews retain their centered final row and four previews remain a two-by-two grid. Gap changes preview during a gesture and commit to `playground.json.ui.previewColumnGap` and `previewRowGap` at gesture end through the shared revision-guarded save queue. Reset preview spacing resets only these two values. Library shows only View pill controls. Scene and Version filter buttons size to their labels with a 16px gap. At phone widths Library filters, density and search wrap into full-width rows; the filter gap is 12px and long labels truncate.

Opening an editor from a Library card or a Playground preview carries its currently presented image and local clip time into the editor. The frame moves and resizes to the measured editor canvas while the composition list, inspector and timeline enter from the left, right and bottom viewport edges. Playground's clip canvas exits downward at the same time. Returning reverses the spatial handoff to the original Library card or Playground preview; editor panels exit and the Playground canvas slides back up. The 2D / Camera switch travels as one group with the bottom panel on entry and return, with its temporary presentation above the moving frame and outside panel clipping. Every part uses 500ms and cubic-bezier(0.5, 0, 0, 1). Incoming surfaces remain hidden until their first animation keyframes are installed, preventing a flash at their final positions. A temporary copy of the existing preview pixels covers editor preparation, then hands off to the matching rendered frame; no additional source capture is needed for the transition image. Workspace selection, filters and layout remain mounted across the editor visit. Closed editor panels expand to their remembered sizes. Transitions preserve the thumbnail crop during resizing, suspend outgoing playback, and clean up on navigation or resize. Reduced motion skips the spatial animation. The Playground Open editor button uses white text over a 50%-black blurred body, transitioning to solid black on hover over 200ms in both themes.

Canvas hover previews float above and left-align with the hovered sequence. Connected clips share one row and one sequential clock: only the current card moves, while completed cards retain their last frame and upcoming cards show cached posters. The row scales down or shifts to stay within the viewport, and flips below the clips when there is insufficient room above. Pointer hover and keyboard focus open immediately. Each frame fades from zero opacity and scales from 80% to 100% over 200ms with a strong ease-out, anchored at its bottom-left corner. Connected frames enter with an 80ms stagger. Dismissal retains the last pixels for a simultaneous 200ms fade and scale back to 80%, using the time-reversed entry curve and no stagger. Playback stops as soon as dismissal begins. Reduced-motion preferences skip the transition. Leaving, dragging, pinching, Escape, switching views or hiding the page releases the floating preview. It never changes the main transport clock or selection. Rendering defaults to 10fps, density 1 and a 480×300 output cap; only the current and next live renderers are retained, and the next clip warms in the background. Static cards reuse the shared serialized poster cache. Visible posters preload during idle time, and cached pixels are read synchronously when floating previews mount. Canvas and Library use the same project-and-revision cache keys. Pointer approach within 120px prepares a nearby clip before hover; up to two idle hover renderers are kept for reuse, with exclusive ownership transferred to the live preview. Revision changes, project exit and page hiding clear idle resources. The first uncached visit can still wait for source capture; cached images cover preparation on subsequent visits.

Dial Kit's Hover previews section controls Frame width (80px), Frame height (45px), Frame spacing (8px), Above clip (12px), Frame corners (4px), Window padding (4px), Window corners (10px), Frame rate (10fps) and Hover delay (0ms). These nine fields persist in `playground.json.ui`. Adjusting a hover control keeps a sample visible until the panel closes, and Reset hover previews resets only these fields. Preview dimensions are screen pixels and stay independent of canvas zoom and authored scene output.

The approved box and snap values remain in `playground.json.ui`: zero joined gap, 26px snap reach, 3px line width, a 143° gradient, 12.2px starting length, 45.2px ending length, 12px line rounding, 1.5px play pin width, 8px box corners and hidden version tags. Legacy line height and starting scale migrate to equivalent pixel lengths. Width can follow duration (base width plus pixels per second, with minimum/maximum clamps) or use one uniform width; composition details can override a single clip's width and fill color. The shared width function drives displayed bounds, chain reflow, snapping and drag geometry. Existing style values, composition overrides, arrangements and feedback marks are preserved when changing or resetting preview spacing. Older UI files derive independent tag size, duration size and tag gap from their existing clip font size and title–version gap.
