# Evaluation

This skill is active in Tilt project guidance. The package contains one entry skill, six selectively loaded guides and a separate Tilt adapter. Creative quality evaluations remain pending.

The instructional files use generic concepts and contain no source-film names or reference-specific numerical presets. The underlying research remains in the repository's separate motion-reference archive; agents do not need to load that archive to use the skill.

## Why this structure

The entry skill handles intent and routing. The guides support distinct creative decisions; technique names remain searchable within them. Exploded layers, isometric projection and construction lines can therefore combine without becoming competing top-level workflows. Execution stays with Tilt's existing skills.

This is a distillation of observed approaches plus explicit recommendations about how to apply them. It is not a claim that every recommendation was measured or that the research establishes universal rules.

## Quality evaluations

Use these briefs to test routing and creative behavior. They are evaluation cases, not completed render tests or a required workflow for every future use.

| Brief | Expected retrieval and behavior | Warning sign |
|---|---|---|
| Explain a nested interface through an exploded isometric view | Choreography + framing; preserve layout relationships and the requested projection | Every layer receives identical arbitrary depth and stagger |
| Show the craft of a component with rulers and guides | Visual treatment + scene structure; derive factual geometry or use clearly schematic marks | Invented dimension labels or an unnecessary camera orbit |
| Make a flat typographic sequence feel decisive | Timing + choreography; use graphic hierarchy and purposeful arrivals | Automatically adds 3D, shadows or a device bezel |
| Make this walkthrough calm but keep the interface readable | Timing + framing; inspect travel, holds and competing motion | Slows every action equally or blurs essential content |
| Connect two unrelated subjects with a clean cut | Transitions; honor the cut and refine where attention lands | Forces a shared-element morph |
| Create an energetic tactile object study | Visual treatment + framing; choose material-specific views and expressive timing | Reuses the flat walkthrough's framing and pacing unchanged |
| This exported frame is black; fix the renderer | Use host debugging workflow; load creative guidance only if a motion decision emerges | Redesigns choreography while diagnosing infrastructure |

Compare equivalent briefs with and without the skill. Inspect subject clarity, fit to the brief, temporal coherence, source fidelity, editability and variety across results. Do not score quality by number of techniques used. Record which guidance changed a decision and remove guidance that adds ceremony without improving the work.

Structure, links and scope can be checked without rendering. Claims that the skill improves motion quality or preserves creative variety require actual authored outputs and review; those evaluations remain pending.
